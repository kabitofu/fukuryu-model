### おおよその構想の流れ:  
0. 今のAIは理性がない  
1. 今のAIは思考の連続性が足りない  
2. 連続性のためにはレイヤーを無限化する必要がある（ループか都度新生か）  
3. 思考の1次元化を避けるためには複雑な流れがなければならない  
4. ノードの接続方式を有向グラフにする  
5. VSAを知ったのでノードにVSAを入れてみる  
6. 関連性を使った処理を思いつく  
7. 関連性で処理できるならノードが動いてもいい  
8. 高次元ベクトルを2次元有向グラフ空間で扱い、有向グラフでは勝手に近いベクトルで集まり合ってクラスタリングが進む設計に  
9. 温度による状態変化を思いつく（物質の三態）  
10. 長期記憶と処理軽減を思いつく（ノードの凝固）  
11. 階層構造化（物理層である意味整理層、論理層である意味流通層と意味処理層）
（もっと色々ありましたが整理しないと思い出せません）（流通層でも整理するので意味整理層はもうちょっとマシな名前ありそう）

### 結局何:  
GW中に思いついてとりあえず1か月ほど考えみたら _やけに見た目が整っていて振り回しがいのありそうな木の棒_ みたいなものができてきたので、役立ちそうなら役立ててほしくて、そうでないならほっといてくださいというものです。意味流通自己組織的ネットワークとか色々呼んでます。よくわかりません。  
一度勢いに任せて検証に入りましたが設計をまとめていなかったので途中で詰んでバックしているところです。  
私に質問したところで基本的な思想から導出できるフワッフワした応答しかできないと思います。私は雰囲気で設計をやっている。  
あとこれたぶん何らかのエネルギーに引き寄せられて結果的になにか生まれるような構造のものに広く応用できるような気がします。複雑系というものは大概そうなのかもしれませんが・・・  
正直なところまだあまり価値があるとは思っていません。  
あと要約やまとめはとりあえずAIにお願いしました。変なところありそう。

### 🤝 「一人で考えるのは限界が来たので、勝手に遊んでください」  
このモデルは、既存のディープラーニング（バックプロパゲーション等）の枠組みに対するカウンターとして、熱力学・経済メタファー・VSA（高次元ベクトル空間）を融合させた、局所判断のみによる自律創発ネットワークを目指しています。  

ただ、局所温度の因果やエネルギー経済のパラメータ調整など、抽象度と複雑さの迷宮を一人で歩き続けるには脳のスタミナが限界を迎えました。
