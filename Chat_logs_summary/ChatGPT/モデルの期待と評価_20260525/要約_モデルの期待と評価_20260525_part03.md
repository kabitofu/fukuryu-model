## 1. 議論の概要

本セッションでは、最新の仕様を反映した技術ブログ「伏流モデル v0.002：知能が自然発生する場の設計」の修正案（節設計）をベースに、アーキテクチャの構造化、アルゴリズムの物理法則への落とし込み、および実装に向けた課題の抽出について議論された。

設計者は、自身の「ローグライクゲーム」や「Minecraftの高難易度MOD/手動切り分け」などの経験をベースにした、徹底的な「パラメータ微調整への耐性」や「出来上がったものを捨ててやり直す破壊耐性（理論防衛モードに陥らない姿勢）」を活かし、期待する挙動への無理な誘導（チート）を排除した「勝手に起きる想定外の創発」を観測することの重要性を共有した。

## 2. システム仕様・実装方針（最新の決定・洗練事項）

前回の仕様からさらにブラッシュアップされ、概念の依存順が整理された。また、読者の誤解を防ぐため「比喩表現をアルゴリズム的抽象度へ引き上げる」方針が確認された。

### 【要素定義と5原則の洗練】

1. **信号は栄養であり毒でもある（自律動機・過負荷リスク）:** ノードは発火（信号）がないと「くっつきやすさ」が低下して消滅するため、能動的に信号を求める。ただし、過剰な信号（過飽和）は死のリスクを高める。このため、強者ノードであっても信号を独占せず、周囲へ分散（アウトプット）させる動機が生まれ、中央集権化が自動抑制される。
2. **誘蛾灯モデル（クラスタの引力）:** クラスタの発火連鎖が光となり、自身の波長（VSAベクトル）に近い漂流ノードを引き寄せる。
3. **局所判断のみ:** 各ノードは近傍1ホップだけを見て独立して判断する。全体最適化を持たないため、FPGAの並列処理（Tang Nano）と完全に合致する。
4. **動的クラスタ形成（新陳代謝）:** 中心で発火過多になったノードが緩やかに死んで内側に空きができ、外周から新しいノードが沈み込む流動的な構造を維持する。
5. **エッジなし（接続の現象化）:** エッジを設計上の実体として定義せず、「ノードのくっつきやすさの差」と「ベクトルの波長の近さ」から条件が揃ったときだけ放電が起きる（アーク放電のイメージ）接続状態として定義する。初期の「エッジが一切存在しない」という思想から、「固定配線として定義しない（接続は結果としての現象）」という仕様へ洗練された。

### 【四層階層とデータ構造】

* 階層構造は `VSAベクトル → ノード → クラスタ → 野`。
* 各階層の「圧（発火頻度やノード数比率）」が移動や新ノード補充（確率的）を決定する。
* ノードが持つ情報は、意味内容を示す「VSAベクトル」、接続強度や引力を一括表現する単一パラメータ「くっつきやすさ（発火で飽和曲線上昇、放置で指数減衰）」、モダリティ境界を管理するメタデータ「野タグ」、累積信号量を示す「信号の飽和度」。**野タグをベクトルの外側に置く**ことで、ベクトル演算と境界管理を分離する。

### 【ドキュメント・記述方針の決定】

* **LLM（次トークン予測）との差異の明示:** 記事の冒頭に「なぜLLMでは足りないのか」を配置し、思考の連続性・身体・生存動機の重要性を説く。
* **3段構成の採用:** 読者の理解を深めるため、各機能を「比喩（誘蛾灯など） → 抽象（局所発火密度など） → 実装候補（具体的な値や計算式）」の3段階で記述する。
* **脳部位アナロジーの注記:** 視床（ハブ）や連合野などの表現はあくまで「参考程度の比喩（普遍的通信構造が主目的）」であることを明記する。

## 3. 理論的前提（複雑系の観測技法）

* **「観察学」としてのスタンス:** 設計通りに完璧に動くシステムは「ルール埋め込み」の恐れがあるため、「半分だけ当たる（例：クラスタ化するが暴走する）」ような想定外の挙動を歓迎し、失敗（固定化、ループ閉鎖）の条件を切り分ける「自然観察者」としてのスタンスを前提とする。
* **未整理状態の維持:** 早く答えを固定して製品化を目指すエンジニア思考ではなく、流動状態・仮説途中の未完成な「原理の断片」をホールドし、変形過程をオープンに公開（NYSLライセンス採用）しながら外部化していく。

## 4. 未解決の課題・実装時のボトルネック

実装に向けて具体的に詰め切るべき力学法則（物理法則の確定）として、以下の5系統が挙げられている。

* **「場」の実体の数理化:** 1ホップ伝播で全探索の重さを代替できるか。引力の減衰、波長一致の具体的な計算、同時候補が複数ある場合の優先度定義。
* **時間スケール問題（時間比率の決定）:** 発火・飽和・減衰・死・漂流・学習のそれぞれの速度比率のチューニング。減衰が遅すぎれば固定化し、飽和が速すぎれば全滅する。
* **エネルギー保存則（信号総量）の定義:** 信号の消滅条件（ホップ数上限か強度の下限か）。正帰還による無限増幅・爆発をガードする不応期や損失の設計。
* **感覚野間の境界維持の検証:** 長期学習が進んだ際、感覚野間の境界が保たれるか。位置情報・時空間タグをどう深く組み込むか。
* **各関数の具体的な形:** 信号の飽和度と「超新星（過負荷死）」の発生確率の関係など、具体的な関数を差し替え検証で比較評価する手法。
